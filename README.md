# Retail Shop Network

A small retail shop network built in Cisco Packet Tracer. I'm building it in stages, adding new features as I learn them in the Cisco Networking Academy networking basics course.

Each version has its own folder with the Packet Tracer file, a topology picture, device configs, and notes on what I built, tested, and learned.

## Versions

| Version | What it adds | Status |
|---|---|---|
| [v1-basic-shop](v1-basic-shop/) | Router, switch, 3 devices and a printer with static IPs | Done |
| v2 | DHCP and a wireless access point for guests | Planned |
| v3 | VLANs to separate POS, staff and guest traffic | Planned |
| v4 | Internet access, NAT and DNS | Planned |
| v5 | Security: ACLs, SSH and port security | Planned |

## Tools

- Cisco Packet Tracer
- Cisco IOS command line

## How to open a version

1. Download the `.pkt` file from the version's folder.
2. Open it in Cisco Packet Tracer.
3. Read the `notes.md` in the same folder for the IP plan, tests and lessons learned.
